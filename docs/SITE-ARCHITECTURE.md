## Appendix C. How this was computed

- **Parser**: a dependency-free HTML tree builder (implied end tags, raw-text elements, foreign SVG) inlined in `tools/write-architecture.mjs`. It is a copy of `tmp/wf1/arch/lib-dom.mjs`: `tmp/wf1/arch/parser-equiv.mjs` checks that both build identical trees on all 148 raw pages, and `tmp/wf1/arch/test-dom.mjs` checks lib-dom on synthetic edge cases and requires its tag counts to equal regex counts for 14 element types on every raw page. The independent re-derivation of the load-bearing counts (regex over the raw bytes, plus positive controls for every zero-result detector) is `tmp/wf1/arch/verify.mjs`. The script also self-tests the parser and its CSS reader on every run and stops if either fails.
- **Families**: `FAMILY_RULES` in the script (body classes `single-template`, `home`, `archive`, `single-post`, `single-team`, `single-testimonial`, `single-location`, `page`; presence of `div.ecp-secondary`, `div.gform_wrapper`, `div.ecp-posts-wrapper-post.ecp-view-summary`; paths for not-found / sitemap / legal). The partition check uses a mutation positive control.
- **Chrome identity**: SHA-1 of the label/href/src sequence of `header.ecp-header` + `footer.ecp-footer` (and of `div.ecp-secondary` for the sidebar) per page.
- **Row backgrounds**: node rules `.fl-node-<id> > .fl-row-content-wrap` (and `:after` overlays) read from `link[rel=stylesheet]` files mapped through `stylesheets.json` to `audit/css/`, plus every inline `<style>`. `rel="UNUSEDstylesheet"` is not loaded by a browser and is ignored.
- **Leaks**: shortcodes `/\[name attr='v'\]/` and bracketed template instructions in visible text nodes (outside head/script/style), placeholder phrases (555-555-5555, "(location description)", "Centerville Plaza", "name of practice", lorem ipsum) and empty `tel:` hrefs.
- **Robots**: every `meta[name=robots]` is read, and a page is effectively noindex if any of them says noindex.
- **Home computed-style capture**: 4 `index.<width>.json` files in `tmp/capture/baseline` record the home URL (written by the re-capture logged in `tmp/capture-home.log`, 4 capture lines). The first capture run was given `C:/Program Files/Git/` instead of `/` (6 lines in `tmp/capture-run.log`; Git Bash path conversion, avoid with `MSYS_NO_PATHCONV=1`). This document does not depend on those captures: section 5 is read from `audit/raw/index.html`, the stylesheets and the `tmp/live/` screenshots.
